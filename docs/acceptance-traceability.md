# Acceptance traceability

This matrix is the final-review mapping of the 44 approved requirements to
repeatable repository evidence.  Requirement wording is deliberately concise;
the approved source remains the [design specification](superpowers/specs/2026-07-19-medication-reservation-system-design.md).

## Status meaning

- **Automated PASS** — source-level Node contract or release-gate evidence passed in the final-review run. It does not represent a browser render or a live Apps Script execution.
- **Rendered browser PASS** — a real rendered-browser check proves the full criterion within the documented frontend environment. It does not imply live backend or deployment acceptance.
- **Pending operator/live UAT** — requires a deployment owner, disposable test Sheet, configured Web App/Pages deployment, or a rendered browser. It is not claimed to have passed.

Exact UAT identifiers are defined in [the UAT checklist](uat-checklist.md). The six `AS-*` suite entries are expected outcomes only and remain pending until the operator records dated evidence.
